Tentang Saya

Saya adalah siswa SMK jurusan Rekayasa Perangkat Lunak yang memiliki semangat untuk terus belajar dan berkembang di bidang teknologi informasi. Selama menempuh pendidikan, saya telah mempelajari berbagai dasar pemrograman, pengembangan website menggunakan HTML, CSS, JavaScript, PHP, dan Laravel, pengelolaan database menggunakan MySQL, serta pembuatan game sederhana menggunakan Godot Engine.

Selain mengikuti pembelajaran di sekolah, saya juga berusaha mengembangkan kemampuan dengan mengerjakan berbagai proyek pribadi sebagai sarana latihan dan menambah pengalaman. Saya percaya bahwa konsistensi, rasa ingin tahu, kemampuan bekerja sama, dan kemauan untuk terus belajar merupakan bekal penting untuk menjadi seorang software developer yang kompeten di masa depan.

Melalui portofolio ini, saya ingin menunjukkan hasil belajar, pengalaman, dan perkembangan kemampuan yang telah saya capai selama menjadi siswa Rekayasa Perangkat Lunak.
